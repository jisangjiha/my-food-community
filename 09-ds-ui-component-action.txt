다음 디자인시스템 가이드에 맞게 UI 컴포넌트를 렌더할 것.

===

1. 공통조건:
    - 프레임:
      - 컴포넌트 1개당 신규 프레임 1개
    - 소스:
      - 화면 내 디자인 시안 반영
      - 컬러는 시맨틱 토큰에서 선택
      - 텍스트는 타이포그래피 프레임에서 선택
      - 아이콘은 아이코노그래피 프레임에서 선택
      - 버튼, 아이콘버튼 등의 컴포넌트는 이미 만들어져 있는 컴포넌트 프레임에서 선택
    - 정렬:
      - 타입(행) * 상태(열)
    - 색상:
      - subtle 계열(파스텔/틴트)은 명시하지 않는 한 사용 금지
      
2. 개별조건:
    - 버튼:
      - 타입:
        - primary, secondary, destructive
        - 각 타입별 영역 분리
      - 상태:
        - default, disabled, loading
          - loading: 좌측 아이콘을 스피너로 대체, 레이블 유지
      - 사이즈:
        - sm(32), md(40), lg(48)
      - 구조:
        - 레이블
          - 레이블 사이즈: label-lg
        - 레이블 좌/우측에 아이콘 추가/제외 가능
          - 아이콘 사이즈: 
            - sm: 16px
            - md: 20px
            - lg: 20px

    - 아이콘버튼:
      - 이미 완료된 상태이므로 수정 금지
      
3. 컴포넌트 생성:
    - 대상:
      - 위에서 렌더한 각 컴포넌트 영역 프레임내
        - 신규 프레임 생성하지 않음
      - 방식:
        - 타입 * 상태 개수 만큼 각 각 컴포넌트 생성
      - 주의사항:
        - 컴포넌트 핵심부를 컴포넌트로 만들어야하며, 이를 감싸는 바깥 영역은 컴포넌트가 되어서는 안됨
        
4. 최종 검토사항
    - [  ] 공통조건의 프레임을 만족 하였는지 확인
    - [  ] 공통조건의 소스를 만족 하였는지 확인
    - [  ] 공통조건의 정렬을 만족 하였는지 확인
    - [  ] 공통조건의 색상을 만족 하였는지 확인
    - [  ] 개별조건의 버튼을 만족 하였는지 확인
    - [  ] 개별조건의 아이콘버튼을 만족 하였는지 확인
    - [  ] 위 2개의 컴포넌트가 각 각 컴포넌트 생성 조건을 만족하였는지 확인
