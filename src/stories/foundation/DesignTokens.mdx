# 디자인 토큰

`design.pen`의 `variables`를 그대로 옮긴 것입니다. 이름을 바꾸지 않았기 때문에
디자인 파일의 토큰 이름, Storybook에 표시되는 이름, Tailwind 유틸리티 이름이 항상 일치합니다.

- 정의: `src/app/globals.css`의 `@theme` 블록 (CSS 변수 / Tailwind 테마)
- 문서·검증용 미러: `src/tokens/*.ts`

두 곳에 값이 존재하므로 디자인이 바뀌면 **둘 다** 갱신해야 합니다. 이 문서 페이지는
TS 미러를 읽어 렌더하고, 색 견본은 CSS 변수를 읽습니다. 두 값이 어긋나면 아래
"토큰 정합성" 표에 불일치로 표시됩니다.

## 계층

프리미티브 → 시맨틱 2단계입니다.

| 계층 | 예시 | 값 |
| --- | --- | --- |
| 프리미티브 | `color-brand-600` | `#8B4E89` (실제 hex) |
| 시맨틱 | `color-text-brand` | `color-brand-600` 참조 |

시맨틱 토큰은 hex를 직접 갖지 않습니다. 컴포넌트를 만들 때는 프리미티브가 아니라
시맨틱 토큰을 쓰세요. 프리미티브는 팔레트를 보여줄 때와 시맨틱 토큰을 정의할 때만 씁니다.

## 스페이싱

`spacing-20`은 디자인 파일 변수에는 있지만 `14-ds-foundation-spacing.txt`의
용도 목록에는 빠져 있습니다. 용도가 정해지면 채워 넣어야 합니다.

## Tailwind에서 쓰기

`@theme`에 넣었기 때문에 별도 설정 없이 유틸리티가 생성됩니다.

```tsx
<div className="bg-background-canvas text-text-default border-border-default">
<p className="text-text-muted">…</p>
<button className="bg-background-brand text-text-on-brand">…</button>
```

시맨틱 토큰 이름이 그대로 유틸리티가 되므로 `text-text-default`,
`bg-background-brand`처럼 접두사가 겹쳐 보입니다. 디자인 파일과 1:1로 추적되는 쪽을
택한 결과입니다. 짧은 별칭이 필요하면 `@theme`에 추가하면 되지만, 그러면 이름이 두 벌이 됩니다.

## 주의: Tailwind 기본값을 덮어씀

디자인 시스템이 스케일을 소유하도록 아래 기본값을 의도적으로 덮어썼습니다.

| 항목 | Tailwind 기본 | 이 디자인 시스템 |
| --- | --- | --- |
| `neutral` / `amber` / `green` / `blue` / `rose` 팔레트 | Tailwind 색상 | 디자인 파일 색상 |
| `leading-tight` | 1.25 | **1.2** |
| `leading-normal` | 1.5 | **1.4** |

`text-100` ~ `text-900`은 Tailwind 기본 `text-sm`/`text-base` 등과 별개로 추가된 것입니다.
기본 크기 유틸리티도 그대로 남아 있으니, 디자인 시스템 안에서는 `type-*` 클래스나
`text-100`~`text-900`만 쓰세요.
