다음 디자인시스템 가이드에 맞게 UI 컴포넌트를 렌더할 것.

===

1. 공통조건:
    - 프레임:
      - 컴포넌트 1개당 신규 프레임 1개
    - 소스:
      - 화면 내 디자인 시안 반영
      - 컬러는 시맨틱 토큰에서 선택
      - 텍스트는 타이포그래피 프레임에서 선택
      - 아이콘은 아이코노그래피 프레임에서 선택
      - 버튼, 아이콘버튼 등의 컴포넌트는 이미 만들어져 있는 컴포넌트 프레임에서 선택
    - 정렬:
      - 타입(행) * 상태(열)
    - 색상:
      - subtle 계열(파스텔/틴트)은 명시하지 않는 한 사용 금지

2. 개별조건:
    - 카드:
      - 타입:
        - 없음
      - 상태:
        - 없음
      - 사이즈:
        - 가로: auto
        - 높이: auto
      - 구조:
        - 이미지 영역 추가/제외 가능
    
    - 배지:
      - 타입:
        - neutral, success, error, info, warning
      - 상태:
        - 없음
      - 사이즈:
        - md(20), lg(24)
          - md 좌우 패딩: 8px
          - lg 좌우 패딩: 8px
      - 구조:
        - 레이블
          - 레이블 정렬: 가운데 정렬
          - 레이블 사이즈: label-md
        
    - 엠티:
      - 타입:
        - 없음
      - 상태:
        - 없음
      - 사이즈:
        - 없음
      - 정렬:
        - 가로/세로 중앙 정렬
      - 구조:
        - 비주얼 추가/제외 가능
          - 아이콘 또는 그림 영역
        - 제목
          - 제목 사이즈: heading-sm
        - 설명 추가/제외 가능
          - 설명 사이즈: body-md
        - 액션 추가/제외 가능
          - 버튼 primary 타입 1개
          - 버튼 secondary 타입 1개
    
    - 모달:
      - 타입:
        - 없음
      - 상태:
        - 없음
      - 사이즈:
        - 가로: auto
        - 높이: auto
      - 구조:
        - 헤더에 제목과 닫기 아이콘 영역
          - 제목 텍스트 사이즈: heading-so
          - 아이콘 사이즈: 16px
        - 바디에 콘텐츠 영역
          - 본문 텍스트 사이즈: body-md
        - 푸터에 버튼컴포넌트 영역
          - 버튼 primary 타입 1개
          - 버튼 secondary 타입 1개
        - 배경에 스크림
          - 탭하면, 모달 닫힘
    
    - 바텀시트:
      - 타입:
        - 없음
      - 상태:
        - 없음
      - 사이즈:
        - 가로: 가로 전체
        - 높이: auto
      - 구조:
        - 상단에 드래그 핸들
        - 중앙에 콘텐츠 영역
        - 배경에 스크림
          - 탭하면, 선택 없이 닫힘
    
    - 메뉴:
      - 타입:
        - 없음
      - 상태:
        - 없음
      - 사이즈:
        - 가로: auto
        - 높이: auto
      - 연결범위:
        - 활성화시, 메뉴아이템 연결
          - 모바일: 바텀시트내 메뉴아이템
          - 데스크톱: 메뉴버튼 아래의 메뉴아이템
          
    - 메뉴아이템:
      - 타입:
        - default, destructive
      - 상태:
        - default, disabled
      - 사이즈:
        - sm(32), md(40), lg(48)
        - 참조하는 메뉴의 사이즈를 따름
      - 구조:
        - 좌측에 아이콘 추가/제외 가능
          - 아이콘 사이즈
            - sm: 16px
            - md: 20px
            - lg: 20px
        - 레이블
          - 레이블 사이즈: body-lg
          
3. 컴포넌트 생성:
    - 대상:
      - 위에서 렌더한 각 컴포넌트 영역 프레임내
        - 신규 프레임 생성하지 않음
      - 방식:
        - 타입 * 상태 개수 만큼 각 각 컴포넌트 생성
      - 주의사항:
        - 컴포넌트 핵심부를 컴포넌트로 만들어야하며, 이를 감싸는 바깥 영역은 컴포넌트가 되어서는 안됨
              
4. 최종 검토사항
    - [  ] 공통조건의 프레임을 만족 하였는지 확인
    - [  ] 공통조건의 소스를 만족 하였는지 확인
    - [  ] 공통조건의 정렬을 만족 하였는지 확인
    - [  ] 공통조건의 색상을 만족 하였는지 확인
    - [  ] 개별조건의 카드를 만족 하였는지 확인
    - [  ] 개별조건의 배지를 만족 하였는지 확인
    - [  ] 개별조건의 엠티를 만족 하였는지 확인
    - [  ] 개별조건의 모달을 만족 하였는지 확인
    - [  ] 개별조건의 바텀시트를 만족 하였는지 확인
    - [  ] 개별조건의 메뉴를 만족 하였는지 확인
    - [  ] 개별조건의 메뉴아이템을 만족 하였는지 확인
    - [  ] 위 7개의 컴포넌트가 각 각 컴포넌트 생성 조건을 만족하였는지 확인
