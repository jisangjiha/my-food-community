다음 컴포넌트 가이드에 맞게 아이콘 버튼 컴포넌트를 렌더할 것.

===

1. 아이콘 버튼 컴포넌트 렌더:
    - 대상:
      - 신규 프레임
    - 소스:
      - 아이코노그래피 프레임에 렌더된 아이콘중 하트 아이콘 24*24 1개
    - 종류:
      - 고스트 배경
        - 사이즈 48*48
        - 배경색, 테두리 없음
      - 원형타입1 배경
        - 사이즈 48*48
        - 배경색 브랜드 컬러
          - 시맨틱 토큰 사용
      - 원형타입2 배경
        - 사이즈 48*48
        - 배경색 뉴트럴 컬러
          - 시맨틱 토큰 사용

2. 컴포넌트 생성:
    - 대상:
      - 위에서 렌더한 아이콘 버튼 영역 프레임
        - 신규 프레임 생성하지 않음
      - 방식:
        - 아이콘 버튼 1종류당 1개의 컴포넌트 생성
      - 주의사항:
        - 아이콘 버튼을 컴포넌트로 만들어야하며, 이를 감싸는 바깥 영역은 컴포넌트가 되어서는 안됨
      
2. 최종 검토사항
    - [  ] 아이콘 종류 개수가 모두 맞는지 확인
    - [  ] 아이콘 배경색이 명시된 경우, 시맨틱 토큰이 사용되었는지 확인
    - [  ] 아이콘 버튼 프레임내의 아이콘 버튼들이 모두 컴포넌트로 전환되었는지 확인
    - [  ] 주의사항이 모두 반영되었는지 확인
