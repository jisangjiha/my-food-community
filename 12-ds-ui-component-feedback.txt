다음 디자인시스템 가이드에 맞게 UI 컴포넌트를 렌더할 것.

===

1. 공통조건:
    - 프레임:
      - 컴포넌트 1개당 신규 프레임 1개
    - 소스:
      - 화면 내 디자인 시안 반영
      - 컬러는 시맨틱 토큰에서 선택
      - 텍스트는 타이포그래피 프레임에서 선택
      - 아이콘은 아이코노그래피 프레임에서 선택
      - 버튼, 아이콘버튼 등의 컴포넌트는 이미 만들어져 있는 컴포넌트 프레임에서 선택
    - 정렬:
      - 타입(행) * 상태(열)
    - 색상:
      - subtle 계열(파스텔/틴트)은 명시하지 않는 한 사용 금지

2. 개별조건:
    - 스피너:
      - 타입:
        - 없음
      - 상태:
        - 없음
      - 사이즈:
        - md(24)
      - 색상:
        - 브랜드 컬러
    
    - 스켈레톤:
      - 타입:
        - 텍스트형, 사각형, 원형
      - 상태:
        - 없음
      - 사이즈:
        - 텍스트형: 대상 요소의 행 높이
        - 사각형: 대상 요소의 너비*높이
        - 원형: 대상 요소의 지름
      - 색상:
        - 뉴트럴 컬러
    
    - 토스트:
      - 타입:
        - success, error, info, warning
      - 상태:
        - 없음
      - 사이즈:
        - 모바일: 화면 너비 - 좌우 마진
        - 데스크톱: 400px
      - 구조:
        - 좌측에 타입별 상태 아이콘
          - 아이콘 사이즈: 20px
        - 메시지 텍스트
          - 텍스트 사이즈: body-md
        - 우측에 닫기 아이콘 추가/제외 가능
          - 아이콘 사이즈: 20px
          
3. 컴포넌트 생성:
    - 대상:
      - 위에서 렌더한 각 컴포넌트 영역 프레임내
        - 신규 프레임 생성하지 않음
      - 방식:
        - 타입 * 상태 개수 만큼 각 각 컴포넌트 생성
      - 주의사항:
        - 컴포넌트 핵심부를 컴포넌트로 만들어야하며, 이를 감싸는 바깥 영역은 컴포넌트가 되어서는 안됨
              
4. 최종 검토사항
    - [  ] 공통조건의 프레임을 만족 하였는지 확인
    - [  ] 공통조건의 소스를 만족 하였는지 확인
    - [  ] 공통조건의 정렬을 만족 하였는지 확인
    - [  ] 공통조건의 색상을 만족 하였는지 확인
    - [  ] 개별조건의 스피너를 만족 하였는지 확인
    - [  ] 개별조건의 스켈레톤을 만족 하였는지 확인
    - [  ] 개별조건의 토스트를 만족 하였는지 확인
    - [  ] 위 3개의 컴포넌트가 각 각 컴포넌트 생성 조건을 만족하였는지 확인
