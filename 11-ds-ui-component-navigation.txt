다음 디자인시스템 가이드에 맞게 UI 컴포넌트를 렌더할 것.

===

1. 공통조건:
    - 프레임:
      - 컴포넌트 1개당 신규 프레임 1개
    - 소스:
      - 화면 내 디자인 시안 반영
      - 컬러는 시맨틱 토큰에서 선택
      - 텍스트는 타이포그래피 프레임에서 선택
      - 아이콘은 아이코노그래피 프레임에서 선택
      - 버튼, 아이콘버튼 등의 컴포넌트는 이미 만들어져 있는 컴포넌트 프레임에서 선택
    - 정렬:
      - 타입(행) * 상태(열)
    - 색상:
      - subtle 계열(파스텔/틴트)은 명시하지 않는 한 사용 금지
          
2. 개별조건:
    - 탑내비게이션:
      - 타입:
        - 없음
      - 상태:
        - 없음
      - 사이즈:
        - 가로: 가로 전체
        - 높이: 56px
      - 구조:
        - 좌측에 아이콘 버튼 추가/제외 가능
          - 내부 아이콘 사이즈: 24px
        - 제목 텍스트
          - 텍스트 사이즈: heading-sm
        - 우측에 아이콘 버튼 추가/제외 가능
          - 내부 아이콘 사이즈: 24px
    
    - 바텀내비게이션:
      - 타입:
        - 없음
      - 상태:
        - 없음
      - 사이즈:
        - 가로: 가로 전체
        - 높이: 56px
      - 구조:
        - 아이템 2~5개 균등 분배
        - 각 영역에 아이콘 필수
          - 아이콘 사이즈: 24px
          - 미선택 아이콘:
            - 타입: 아웃라인
            - 색상: 뉴트럴 컬러
          - 선택 아이콘: 
            - 타입: 필
            - 색상: 브랜드 컬러
        - 아이콘 아래에 레이블 추가/제외 가능
          - 레이블 사이즈: label-md
    
    - 탭내비게이션:
      - 타입:
        - 없음
      - 상태:
        - 없음
      - 사이즈:
        - 가로: auto
        - 높이: 48px
      - 구조:
        - 아이템 2개 이상 균등 분배
        - 레이블
          - 레이블 사이즈: label-lg
        - 선택시 하단에 인디케이터
          - 인디케이터 사이즈: 2px

3. 컴포넌트 생성:
    - 대상:
      - 위에서 렌더한 각 컴포넌트 영역 프레임내
        - 신규 프레임 생성하지 않음
      - 방식:
        - 타입 * 상태 개수 만큼 각 각 컴포넌트 생성
      - 주의사항:
        - 컴포넌트 핵심부를 컴포넌트로 만들어야하며, 이를 감싸는 바깥 영역은 컴포넌트가 되어서는 안됨
              
4. 최종 검토사항
    - [  ] 공통조건의 프레임을 만족 하였는지 확인
    - [  ] 공통조건의 소스를 만족 하였는지 확인
    - [  ] 공통조건의 정렬을 만족 하였는지 확인
    - [  ] 공통조건의 색상을 만족 하였는지 확인
    - [  ] 개별조건의 탑내비게이션을 만족 하였는지 확인
    - [  ] 개별조건의 바텀내비게이션을 만족 하였는지 확인
    - [  ] 개별조건의 탭내비게이션을 만족 하였는지 확인
    - [  ] 위 3개의 컴포넌트가 각 각 컴포넌트 생성 조건을 만족하였는지 확인
