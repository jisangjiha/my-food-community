다음 디자인시스템 가이드에 맞게 UI 컴포넌트를 렌더할 것.

===

1. 공통조건:
    - 프레임:
      - 컴포넌트 1개당 신규 프레임 1개
    - 소스:
      - 화면 내 디자인 시안 반영
      - 컬러는 시맨틱 토큰에서 선택
      - 텍스트는 타이포그래피 프레임에서 선택
      - 아이콘은 아이코노그래피 프레임에서 선택
      - 버튼, 아이콘버튼 등의 컴포넌트는 이미 만들어져 있는 컴포넌트 프레임에서 선택
    - 정렬:
      - 타입(행) * 상태(열)
    - 색상:
      - subtle 계열(파스텔/틴트)은 명시하지 않는 한 사용 금지
          
2. 개별조건:
    - 텍스트필드:
      - 타입:
        - text, password
        - 각 타입별 영역 분리
      - 상태:
        - default, focused, disabled, error
      - 사이즈:
        - sm(32), md(40), lg(48)
      - 구조:
        - 상단에 레이블
          - 레이블 사이즈: label-lg
        - 입력텍스트(+ 플레이스홀더)
          - 텍스트 사이즈: body-lg
        - 하단에 헬퍼텍스트(힌트, 에러)
          - 에러시 힌트 대체
          - 헬퍼텍스트 사이즈: label-md
        - 입력텍스트 좌/우측에 아이콘 추가/제외 가능
          - 아이콘 사이즈: 
            - sm: 16px
            - md: 20px
            - lg: 20px
    
    - 텍스트에어리어:
      - 타입:
        - 없음
      - 상태:
        - default, focused, disabled, error
      - 사이즈:
        - 고정 높이: 3줄, 내용 초과시 스크롤
      - 구조:
        - 상단에 레이블
          - 레이블 사이즈: label-lg
        - 입력텍스트(+ 플레이스홀더)
          - 텍스트 사이즈: body-lg
        - 하단에 헬퍼텍스트(힌트, 에러)
          - 에러시 힌트 대체
          - 헬퍼텍스트 사이즈: label-md
        - 하단 우측에 글자수 카운터 추가/제외 가능
          - 카운터 사이즈: label-md      
    
    - 체크박스:
      - 타입:
        - 없음
      - 상태:
        - 선택: unchecked, checked, indeterminate
        - 상태: default, disabled, error
      - 사이즈:
        - sm(16), md(20)
      - 구조:
        - 좌측에 체크 영역
          - 아이코노그래피 프레임내 아이콘을 사용하지 않음
        - 우측에 레이블
          - 레이블 사이즈: body-md
          - 체크 영역과의 간격: 8px
      - 연결범위:
        - 단독 사용 가능
        - 그룹 사용 가능
          - 에러 메시지는 전체 그룹(폼) 아래에 1번만 표시
      
    - 라디오:
      - 타입:
        - 없음
      - 상태:
        - 선택: unselected, selected
        - 상태: default, disabled
      - 사이즈:
        - sm(16), md(20)
      - 구조:
        - 좌측에 라디오 영역
          - 아이코노그래피 프레임내 아이콘을 사용하지 않음
        - 우측에 레이블
          - 레이블 사이즈: body-md
          - 라디오 영역과의 간격: 8px
      - 연결범위:
        - 단독 사용 금지
      
    - 스위치(토글):
      - 타입:
        - 없음
      - 상태:
        - 선택: off, on
        - 상태: default, disabled
      - 사이즈:
        - sm(16) 가로:32, md(20) 가로:40
      - 구조:
        - 좌측에 스위치
          - 아이코노그래피 프레임내 아이콘을 사용하지 않음
        - 우측에 레이블
          - 레이블 사이즈: body-md
          - 트랜과의 간격: 8px
      - 연결범위:
        - 단독 사용 전용
      
    - 셀렉트:
      - 타입:
        - 없음
      - 상태:
        - default, focused, disabled, error
          - focused: 패널이 열려있는 동안 유지
      - 사이즈:
        - sm(32), md(40), lg(48)
      - 구조:
        - 상단에 레이블
          - 레이블 사이즈: label-lg
        - 선택값 텍스트(+ 플레이스홀더)
          - 텍스트 사이즈: body-lg
        - 하단에 헬퍼텍스트(힌트, 에러)
          - 에러시 힌트 대체
          - 헬퍼텍스트 사이즈: label-md
        - 우측에 아래 방향 꺽쇠 아이콘
          - 아이콘 사이즈
            - sm: 16px
            - md: 20px
            - lg: 20px
      - 연결범위:
        - 활성화시, 셀렉트아이템 연결
          - 모바일: 바텀시트내 셀렉트아이템
          - 데스크톱: 셀렉트 아래의 셀렉트아이템
          
    - 셀렉트아이템:
      - 타입:
        - 없음
      - 상태:
        - default, selected, disabled
      - 사이즈:
        - sm(32), md(40), lg(48)
        - 참조하는 셀렉트의 사이즈를 따름
      - 구조:
        - 좌측에 텍스트
          - 텍스트 사이즈: body-lg
        - 선택시 우측에 체크 아이콘
          - 아이콘 사이즈
            - sm: 16px
            - md: 20px
            - lg: 20px
      
    - 칩:
      - 타입:
        - 없음
      - 상태:
        - 선택: unselected, selected
        - 상태: default, disabled
      - 사이즈:
        - sm(24), md(32)
          - sm 좌우 패딩: 
	          - 좌측 아이콘 없음: 12px
	          - 좌측 아이콘 있음: 6px
          - md 좌우 패딩:
            - 좌측 아이콘 없음: 16px
            - 좌측 아이콘 있음: 8px
      - 구조:
        - 레이블
          - 레이블 정렬: 가운데 정렬
          - 레이블 사이즈: label-lg
        - 칩내 좌측에 아이콘 추가/제외 가능
          - 아이콘 사이즈: 16px
    
    - 파일업로더:
      - 타입:
        - 드롭존 + 파일선택버튼 결합 단일형
      - 상태:
        - 드롭존: default, dragover, disabled, error
        - 파일아이템: uploading, complete, error
      - 사이즈:
        - 없음
      - 구조:
        - 상단에 헬퍼텍스트(파일 형식·용량 제한 안내)
          - 레이블 사이즈: label-md
        - 드롭존 영역
          - 안내문구 사이즈: body-md
          - 파일선택버튼
            - 버튼사이즈: sm
        - 하단에 파일 아이템 리스트
          - 썸네일
            - 우측에 삭제 버튼
            - 상태 표시
              - uploading: 스피너
              - complete: 체크아이콘
              - error: 에러아이콘

3. 컴포넌트 생성:
    - 대상:
      - 위에서 렌더한 각 컴포넌트 영역 프레임내
        - 신규 프레임 생성하지 않음
      - 방식:
        - 타입 * 상태 개수 만큼 각 각 컴포넌트 생성
      - 주의사항:
        - 컴포넌트 핵심부를 컴포넌트로 만들어야하며, 이를 감싸는 바깥 영역은 컴포넌트가 되어서는 안됨
              
4. 최종 검토사항
    - [  ] 공통조건의 프레임을 만족 하였는지 확인
    - [  ] 공통조건의 소스를 만족 하였는지 확인
    - [  ] 공통조건의 정렬을 만족 하였는지 확인
    - [  ] 공통조건의 색상을 만족 하였는지 확인
    - [  ] 개별조건의 텍스트필드를 만족 하였는지 확인
    - [  ] 개별조건의 텍스트에어리어를 만족 하였는지 확인
    - [  ] 개별조건의 체크박스를 만족 하였는지 확인
    - [  ] 개별조건의 라디오를 만족 하였는지 확인
    - [  ] 개별조건의 스위치(토글)를 만족 하였는지 확인
    - [  ] 개별조건의 셀렉트를 만족 하였는지 확인
    - [  ] 개별조건의 셀렉트아이템을 만족 하였는지 확인
    - [  ] 개별조건의 칩을 만족 하였는지 확인
    - [  ] 개별조건의 파일업로더를 만족 하였는지 확인
    - [  ] 위 9개의 컴포넌트가 각 각 컴포넌트 생성 조건을 만족하였는지 확인
